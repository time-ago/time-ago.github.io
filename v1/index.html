TimeagoFast and lightweight

Date and time library for your Go project that converts dates into 'time ago' format.

Get Started →
🧩

Flexible Date and Time Parsing

Timeago has a flexible date parsing and can parse several different date formats, such as UNIX timestamp, date string like "YYYY-MM-DD HH:MM:SS", and Go's "time.Time" struct

🌍

Support for Multiple Languages

🇬🇧 🇷🇺 🇺🇦 🇳🇱 🇩🇪 🇨🇳 🇧🇾 🇪🇸 🇯🇵 🇫🇷
You can output dates in several different languages such as English, Russian, Chinese, Ukrainian, Dutch, German, and you can easily contribute your own language

⚙️

Configurable Options to Suit Diverse Use Cases

You can configure Timeago to suit your needs to the point where you can even modify the output format of the date, override translation sets, and more

🧪

Comprehensive Testing for Reliability

You cannot find a datetime library that is tested better than this one. It connects to several code quality analyzers and has tests for each supported language

📦

Compact Codebase for a Minimal Footprint

Timeago is designed to be as lightweight as possible, so you can use it in your project without worrying about the size of the binary

✍️

Easy Contribution of the New Language Support

Timeago is designed to be as flexible as possible, so you can easily contribute your own language support to the project following our detailed guidelines
